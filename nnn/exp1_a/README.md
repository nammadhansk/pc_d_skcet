# Exp 1(a): Implementation of Lexical Analyzer using C Programming

## Commands to Execute

### Option 1: Using the CMD script
```cmd
run.cmd
```

### Option 2: Step-by-Step Commands
```cmd
gcc lexer.c -o lexer.exe
lexer.exe
```

## Input to Enter
When prompted with `Enter the C program:`, enter:
```text
int a = 10;
```

## Expected Output
```text
Tokens:
int -> Keyword
a -> Identifier
= -> Operator
10 -> Constant
; -> Special Symbol
```
